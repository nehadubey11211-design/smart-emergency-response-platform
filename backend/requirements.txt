# FILE: backend/requirements.txt
# ======================================
# Python Dependencies
# ======================================
#
# Install all dependencies:
#   pip install -r requirements.txt
#
# Pin EXACT versions (==) in production to guarantee reproducible builds.
#
# NEON MIGRATION CHANGES:
#   The core dependencies are UNCHANGED because Neon is PostgreSQL-compatible.
#   No new libraries are needed — psycopg2 already handles SSL connections.
#
#   The only change is ensuring psycopg2-binary is present (it was already here)
#   because it handles the SSL connection to Neon via the sslmode=require
#   parameter in the DATABASE_URL connection string.
#
#   OPTIONAL ADDITION:
#   If you want to use Neon's HTTP/WebSocket driver instead of the standard
#   PostgreSQL TCP connection, you can install:
#     neon-serverless (Node.js only — not applicable here)
#   For Python with FastAPI, the standard psycopg2 driver works perfectly.
#
# SSL NOTES FOR NEON:
#   psycopg2-binary already includes OpenSSL support.
#   The ?sslmode=require in your DATABASE_URL is enough to enable SSL.
#   No additional SSL libraries are needed in Python.
